# Hash Desk

Local hashing and checksum utility.

This is a small working MVP, not a landing page mockup. I wanted something I could open locally, use immediately, and extend without installing a framework first.

## What works now
- Local browser storage
- Create, edit, complete and delete records
- Fast filtering
- JSON export
- Responsive interface
- No account or backend required

## Run it
Open `index.html`. That's it.

## Notes
The current data model is intentionally simple. Before adding cloud sync, the next step is making the core workflow specific to Hash Desk and adding import/undo support. See `ROADMAP.md`.
